연결 설정 (처음 한 번만)

토큰은 비밀번호와 같아요. 다른 사람이나 채팅에 절대 보내지 마세요.

토큰 만드는 법

  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → 이 저장소만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만료일은 90일 정도로 하고 만들기 → 나온 github_pat_... 를 위 칸에 붙여넣기 (한 번만 보여요)

토큰이 없어도 코드 보기·복사로 만든 내용을 works.js, site.js에 붙여넣을 수 있어요.
