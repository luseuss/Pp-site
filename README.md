# 영상 편집 포트폴리오

설치 없이 `index.html`을 브라우저로 열면 보입니다. (YouTube 재생은 Live Server 또는 배포 주소에서 확인)

## 파일 구조
- `admin.html` / `admin.js` — **관리 페이지** (영상 + 사이트 정보 편집, 저장하면 GitHub의 `works.js` / `site.js`가 바뀜)
- `site.js` — 사이트 정보: 이름, 애니메이션 켜기/끄기, 메뉴·섹션, 첫 화면 문구, 소개 글·이미지, 이메일, SNS 링크 (관리 페이지가 고치는 파일, 직접 고쳐도 됨)
- `works.js` — 영상 목록 (관리 페이지가 고치는 파일, 직접 고쳐도 됨)
- `index.html` — 사이트 뼈대 (글 내용은 `site.js`의 값으로 채워짐. 안에 적힌 문구는 기본값)
- `style.css` — 디자인
- `script.js` — 카드 자동 생성 + 영상 팝업 (보통 건드릴 일 없음)
- `images/` — 사이트에 쓰는 이미지(소개 이미지 등, 관리 페이지에서 올리면 여기 저장)
- `videos/` — 직접 올릴 mp4 (파일당 100MB 미만 권장)
- `thumbs/` — 영상 썸네일 이미지 (관리 페이지에서 올리면 여기 저장)

## 관리 페이지 (admin.html)
사이트 주소 뒤에 `/admin.html`을 붙여 접속합니다. (예: `https://luseuss.github.io/Pp-site/admin.html`)
1. 처음 한 번: "연결 설정"을 펼쳐 GitHub 토큰을 넣습니다. (Fine-grained 토큰, 이 저장소만, Contents: Read and write)
2. **영상** 탭: 영상 추가/수정/삭제, 카테고리, ↑↓로 순서 변경. **사이트 정보** 탭: 이름(로고·탭 제목·푸터), 첫 화면 문구(작은 글씨·큰 제목·한 줄 소개·버튼), 소개 글, 이메일, 링크(Instagram/YouTube/X 등) 추가·삭제·순서 변경. 첫 화면의 칸을 비우면 그 부분이 화면에서 사라집니다.
   - **효과**: 애니메이션 켜기/끄기.
   - **메뉴와 섹션**: 소개·작업물·연락 영역을 켜고 끌 수 있고(끄면 메뉴 링크도 같이 사라짐), 메뉴 글자와 영역 제목을 고칩니다.
   - **이미지**: 소개 이미지와 영상 썸네일을 "이미지 올리기"로 고릅니다. png·jpg·webp는 긴 변 1200~1280px로 자동으로 줄이고, gif는 5MB 이하만 그대로 올립니다. **GitHub에 저장**을 누를 때 영상·사이트 정보보다 먼저 올라갑니다. (안 쓰게 된 옛 이미지는 저장소에 남으므로, 필요하면 GitHub에서 직접 지우세요.)
3. **GitHub에 저장** → 바뀐 파일만 저장되고 1~2분 뒤 사이트에 반영. 순서 번호는 위에서부터 자동으로 1, 2, 3…
- 토큰은 비밀번호와 같습니다. 남에게 공유하지 마세요. 토큰 없이도 "코드 보기·복사"로 `works.js` / `site.js`에 붙여넣을 수 있습니다.
- 관리 페이지에서 저장하면 GitHub가 앞서가므로, 내 컴퓨터에서 작업하기 전에 **Pull**을 먼저 하세요.

## 애니메이션
조용하고 절제된 움직임만 넣었습니다. 모두 `style.css` 맨 아래 "애니메이션" 구역과 `script.js` 맨 아래에 있습니다.
- 첫 화면: 작은 글씨 → 제목 → 한 줄 소개 → 버튼이 차례로 떠오름, 아래쪽 스크롤 안내선
- 스크롤하면 섹션 제목·소개·영상 카드·연락처가 부드럽게 나타남 (카드는 차례로)
- 영상 카드에 마우스를 올리면 살짝 떠오름, 카테고리를 바꾸면 카드가 다시 나타남
- 맨 위 메뉴: 현재 섹션에 밑줄, 스크롤하면 그림자 / 영상 팝업은 부드럽게 열림
- **첫 화면 배경**: 둥근 파동(2개)이 천천히 퍼짐. `transform`·`opacity`만 써서 가볍고, 첫 화면이 화면 밖이거나 탭이 가려지면 자동으로 멈춤. 관리 페이지 **효과**의 "첫 화면 배경 움직임" 또는 `site.js`의 `heroMotion: false`로 끌 수 있음.
- **메뉴 호버**: 메뉴에 마우스를 올리면 올린 메뉴만 또렷하고 나머지는 흐려짐 (순수 CSS)
- **마우스 기울기**: 첫 화면 버튼과 영상 카드가 마우스를 따라 최대 6도 기울어짐. 자주 불리는 `pointermove` 리스너는 마우스가 올라가 있는 동안에만 붙였다가 떼고(평소엔 `pointerover`/`pointerout` 2개뿐), 터치 기기·"동작 줄이기"에서는 시작하지 않음. `site.js`의 `tilt: false`로 끔.
- **스크롤하면 제목 흐려지기**: 스크롤하면 첫 화면 글자가 위로 올라가며 사라짐. 브라우저의 스크롤 연동 애니메이션(`animation-timeline`)을 써서 자바스크립트가 없고, 지원하지 않는 브라우저에서는 가만히 있음. `heroFade: false`로 끔.
- 끄는 법: 관리 페이지 **사이트 정보 → 효과**에서 끄거나(전체 `animations: false`, 배경만 `heroMotion: false`). 방문자가 운영체제에서 "동작 줄이기"를 켜 두면 자동으로 꺼집니다.

## 가볍게 유지하기 (메모리 누수 방지)
- **외부 구성요소 0개**: 프레임워크·라이브러리·빌드 도구·외부 글꼴이 없습니다. 순수 HTML/CSS/JS 이고 코드 전체가 약 35KB 입니다. (영상은 YouTube 임베드이며 카드를 눌렀을 때만 불러옵니다.)
- **리스너는 한 곳에서**: 영상 카드·카테고리 버튼은 카드/버튼마다 이벤트를 달지 않고 한 곳(`grid`, `filters`)에서 처리합니다. (예전에는 카테고리를 빠르게 누를 때마다 리스너가 쌓였고, 고쳤습니다.)
- **영상 팝업**: 닫을 때 `iframe`은 빈 페이지로 바꾼 뒤 제거하고, `video`는 멈추고 주소를 비운 뒤 제거합니다.
- **관찰자·스크롤**: 나타나기 관찰자는 다 나타나면 해제하고, 스크롤 처리는 상태가 바뀔 때만 화면을 건드립니다. 끝없이 도는 애니메이션은 없습니다(스크롤 안내선은 4번만).
- **무거운 효과 제거**: 헤더의 흐림(backdrop-filter) 효과를 쓰지 않습니다. 소개 이미지는 화면 크기에 맞게 600px 로 줄여 두었습니다.
- **관리 페이지**: 올리려고 고른 이미지는 미리보기 주소(blob)와 함께 "지금 쓰는 것"만 메모리에 두고, 바꾸거나 지우면 바로 놓아 줍니다. 줄이기에 쓴 이미지·캔버스도 끝나면 반납합니다.

## 카테고리
영상마다 `tags`를 달면 사이트 작업물 위에 "전체 / MV / AMV" 버튼이 자동으로 생깁니다.
- 관리 페이지: 영상 아래 "카테고리"에 쉼표로 적거나, 이미 쓴 카테고리 버튼을 눌러 붙입니다. (여러 개 가능)
- 직접 고칠 때: `tags: ["MV", "AMV"],` — 대소문자는 구분하지 않습니다.
- `tags`가 없는 영상은 "전체"에서만 보이고, 어떤 영상에도 `tags`가 없으면 버튼 줄이 숨겨집니다.

## 영상 직접 추가하는 법 (works.js)
`works.js`의 목록에 한 덩어리를 복사해서 붙이고 값만 바꾸세요.
```js
{
  order: 1,                          // 순서 번호 (작을수록 앞)
  url: "https://youtu.be/영상ID",   // 유튜브 주소를 그대로 붙여넣기
  title: "작품 제목",
  meta: "2026 · 모션 그래픽",
},
```
mp4는 `url` 대신 `src: "videos/파일명.mp4"`, 썸네일은 `thumb: "thumbs/파일명.jpg"`(선택).
순서는 `order` 번호가 작을수록 앞입니다(번호 없으면 맨 뒤). 맨 앞에 넣으려면 `order: 0`. 숨기려면 줄 앞에 `//`.

## 배포 (무료)
GitHub Pages: Settings → Pages. 주소는 저장소 이름과 대소문자까지 같아야 합니다.
