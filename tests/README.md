# 시험 (tests)

사이트와 관리 페이지가 제대로 동작하는지 자동으로 확인하는 시험이에요. 사이트를 고치고 올리기 전에 한 번 돌려 보세요.
실제 저장소 파일이나 GitHub 는 건드리지 않아요. (사이트 파일을 임시 폴더에 복사해서 열고, GitHub 는 가짜로 흉내 내요.)

## 돌리는 법
```
cd tests
npm install            # 처음 한 번 (Playwright 설치)
npx playwright install chromium   # 브라우저가 없으면 한 번
npm test               # 전체 시험
node run.js admin      # 이름에 admin 이 든 파일만
```
- 끝에 `N passed, 0 failed` 가 나오면 통과예요. 실패하면 `FAIL 이름 >> 이유` 가 나와요.
- 크로미움 위치를 직접 정하려면 환경변수 `CHROMIUM_PATH` 를 쓰세요.

## 들어 있는 것
- `seo.unit.test.js` — 검색·공유 구역을 만들고 읽는 `seo.js` (브라우저 없이)
- `site.test.js` — 검색·공유 태그와 아이콘, 접근성(건너뛰기 링크·팝업 포커스·명암비), 영상 팝업(떠 있는 카드·설명·이미지 격자), 대표 영상, 첫 화면 배경 영상(메모리 누수 없이 만들고 지우는지 포함)
- `admin.test.js` — 관리 페이지: 검색·공유 저장, 효과 체크박스, 대표 영상·설명·이미지 격자 저장
- `harness.js` — 시험 도우미 (임시 웹서버, 가짜 GitHub)

## 알아둘 점
- 시험은 `works.js` 에서 `featured: true` 줄만 뺀 목록으로 시작해요. (대표 영상을 골라 둬도 시험이 흔들리지 않게)
- 사이트 문구나 영상 개수가 바뀌어도 대부분 그대로 통과하게 만들었지만, 파일 이름이나 화면 구조(`.card`, `#modal` 등)를 바꾸면 시험도 같이 고쳐야 해요.
